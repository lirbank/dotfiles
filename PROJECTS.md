## Threads

A thread can run in four modes. ONLY USE NUMBER 4.

1. Cloud. Started with no device.
2. Cloud with folder access. Started with device mode `files`.
3. Cloud with folder access, then a Remote Control session started mid-thread. Two Claudes, and the one on my Mac only gets a summary of the thread.
4. Remote Control session from the first message. Started with device mode `remote_control`. One Claude, on my MacBook. ONLY USE THIS!

Before its first step, every thread runs `uname -ns` and displays the output to the user.

- If the output shows Darwin on uscss-nostromo, the thread title is suffixed " 🖥️", and continues.
- Otherwise the thread title is suffixed " 🌍", stops, and tells me.
- It never starts a Remote Control session.
